# Reproducing the London measles analysis

The archived project includes original Python scripts, the Quarto report source, a bibliography, images, and saved JSON results. At the moment **the files in this GitHub branch do not yet include all of these assets**; they are retained in the prepared local portfolio ZIP until transferred.

The analysis imports JAX, NumPy, pandas, SciPy, Matplotlib, and `pypomp`. Dependency versions and compatibility still require validation. Scripts may use HPC-specific assumptions or relative paths. A full end-to-end rerun has not been completed.

To make this a fully reproducible repository, upload `src/`, `report.qmd`, `report.pdf`, `figures/`, `results/`, `references.bib`, and `submit_final.sh` from the prepared project package, then verify paths and package versions.
